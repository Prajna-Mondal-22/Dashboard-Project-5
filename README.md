# 🛒 Zepto Sales & Business Analytics Dashboard

## 📌 Project Overview
This project is an interactive **Sales & Business Analytics Dashboard** developed using Microsoft Power BI. It focuses on analyzing Zepto's product and sales-related data to generate meaningful business insights through interactive visualizations.

The dashboard helps understand revenue distribution, product performance, category-wise pricing, and city-wise business performance.

## 🎯 Project Objectives
- Analyze total revenue and product distribution.
- Understand city-wise revenue performance.
- Compare current and original prices across categories.
- Identify product-wise revenue contributions.
- Explore business data using interactive filters.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Analytics

## 📊 Dashboard Features

### KPI Cards
- Total Revenue
- Total Products
- Total Cities

### Visualizations
- City-wise Revenue Analysis
- Category-wise Price Comparison
- Product-wise Revenue Distribution
- City-wise Product Category Analysis
- City-wise Current Price Analysis

### Interactive Slicers
- Category
- City
- Influencer Active
